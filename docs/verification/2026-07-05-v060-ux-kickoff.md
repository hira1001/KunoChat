# v0.6.0 UX Kickoff Verification

Date: 2026-07-05

## Scope

- Move KunoChat toward a LINE-like conversation experience.
- Make conversations easier to switch.
- Surface queued sends without making users think about connection internals.
- Improve image inspection with an in-chat preview.
- Preserve the existing send, queue, and transfer behavior.

## Implemented

- Header talk selector redesigned into a compact talk list.
- Talk list now shows unread count, last message preview, relative time, online state, and queued-send count.
- Active chat header shows queued-send count and a friendlier connection label.
- Mini pill now shows queued-send count when there are no unread messages.
- Image messages can be clicked to open an in-app lightbox preview.
